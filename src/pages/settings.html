Google Safe Browsing (optional)

Adds Google's much larger list of dangerous sites on top of the built-in ones. It is free from Google for non-commercial use and needs your own key, which takes about two minutes. HEoBS protects you without it too.

  1. 1. Create a project Sign in to Google if asked, give the project any name, click Create.
  2. 2. Turn on Safe Browsing Check your new project is selected, then confirm. Done when it says the API is enabled.
  3. 3. Create the key “Create credentials” → “API key”. Under API restrictions pick “Safe Browsing API”; leave application restrictions on “None”. Click Create, then copy the key.
  4. Takes the key from your clipboard and checks it with Google straight away.

If Google asks for a payment card at any step, stop: this API does not need one. Ignore any “free trial” banner.

The key is stored encrypted on this PC and is only ever sent to Google. Addresses are checked on this PC; Google is asked to confirm only when a 4-byte fingerprint matches, and never receives the address.

Auto-clear

Have HEoBS tidy up after you automatically. Pick a preset or choose Custom for your own time.

History
Cookies
Cached files

Cookie age is counted from when a site first set the cookie. Clearing cookies signs you out of the sites they belong to. Saved passwords and bookmarks are never auto-cleared. Cached files are copies of images and scripts kept to load pages faster; HEoBS never keeps more than 100 MB of them, and clearing them only makes the next visit to a site a little slower.

Trusted sites

For a trusted site HEoBS keeps the cookies that hold your sign-in, through every auto-clear and through “Clear browsing data”, so the site still recognises this browser and does not make you sign in or verify again. Nothing more is kept: its history is cleared like any other site's, and trackers on it are still blocked.

You can also trust the site you are on from the shield button in the toolbar. A site can still sign you out itself, for example when its own session expires.

Passwords

Other browsers lock their password stores so only they can read them, so the supported route is their own export: in Chrome, Edge or Brave open Settings → Passwords → Export passwords; in Firefox open Passwords → ⋯ → Export passwords. The export file is not encrypted — delete it once it is imported.

Add-ons

HEoBS can run unpacked Chromium extensions. Every add-on must show what it tracks before it can be installed, and you can switch any add-on — or just its trackers — off at any time.

Limits: add-ons are loaded from a folder (there is no store), and Chromium extension features such as toolbar buttons and some browser APIs are not available, so not every extension will work. Requests made by an add-on's scripts inside a web page count as that page's requests and are covered by the normal tracker blocking.

Crash Reports

When HEoBS or a tab crashes, a report is saved on this PC so the problem can be diagnosed. Reports are never uploaded. A crash dump can contain parts of the pages that were open, so only share one with someone you trust.
